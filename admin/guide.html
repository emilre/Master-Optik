Panelin quraşdırılması

Setting up the admin panel

Bir dəfə edilir, təxminən 20 dəqiqə çəkir. Proqramlaşdırma bilgisi tələb olunmur — yalnız iki səhifədə düymələr basılır və iki dəyər kopyalanır.

A one-time job, about 20 minutes. No programming needed — you click through two websites and copy two values.

1. Verilənlər bazası (Supabase)The database (Supabase)

Müştərilər, sifarişlər və anbar Supabase adlı pulsuz bulud bazasında saxlanılır. Pulsuz plan bu ölçüdə bir mağaza üçün tamamilə kifayətdir (500 MB baza, limitsiz istifadəçi).

Customers, orders and stock live in a free cloud database called Supabase. The free plan is more than enough for a shop this size (500 MB of data, unlimited users).

Hesab açınCreate an account

supabase.com → Start your project → GitHub və ya Google hesabı ilə daxil olun. Kart məlumatı istənmir.

supabase.com → Start your project → sign in with GitHub or Google. No card required.

Yeni layihə yaradınCreate a project

New project düyməsi. Ad: master-optik. Database password — güclü şifrə yazın və onu bir yerdə saxlayın. Region: Frankfurt (eu-central-1) — Bakıya ən yaxınıdır. Create new project. Hazırlanması 1–2 dəqiqə çəkir.

Click New project. Name: master-optik. Database password — pick a strong one and store it somewhere safe. Region: Frankfurt (eu-central-1), the closest to Baku. Create new project. It takes 1–2 minutes to build.

Cədvəlləri yaradınCreate the tables

Sol menyudan SQL Editor → New query. Bu depodakı admin/schema.sql faylını açın, bütün mətni kopyalayıb pəncərəyə yapışdırın və Run basın. Aşağıda Success yazısı görünməlidir. Fayl təkrar işlədilə bilər — səhvən iki dəfə işlətsəniz heç nə pozulmur.

In the left menu open SQL Editor → New query. Open admin/schema.sql from this repository, copy all of it into the editor and press Run. You should see Success. The file is safe to re-run — running it twice breaks nothing.

Giriş hesabı yaradınCreate your login

Authentication → Users → Add user → Create new user. E-poçt və şifrə yazın, Auto Confirm User seçimini işarələyin. Bu, panelə giriş məlumatınızdır. İşçilər üçün də eyni qaydada əlavə hesablar aça bilərsiniz.

Authentication → Users → Add user → Create new user. Enter an email and password and tick Auto Confirm User. That is your admin login. Add more users the same way for staff.

İki dəyəri kopyalayınCopy the two values

Project Settings (dişli çarx) → API. Lazım olan iki dəyər: Project URL və anon public açarı. service_role açarını heç vaxt kopyalamayın — o gizli qalmalıdır.

Project Settings (the gear) → API. You need two values: the Project URL and the anon public key. Never copy the service_role key — that one must stay secret.

anon açarı gizli deyil — o, saytın hər ziyarətçisinin brauzerinə düşür və bu normaldır. Bazadakı «Row Level Security» qaydaları ziyarətçiyə yalnız sayt mətnlərini və görünən Instagram paylaşımlarını oxumağa icazə verir. Müştəri, sifariş və anbar məlumatlarına yalnız şifrə ilə daxil olan istifadəçilər çata bilər. The anon key is not a secret — it ships to every visitor's browser and that is by design. The database's Row Level Security rules let a visitor read only the website copy and the visible Instagram posts. Customers, orders and stock are reachable only by users who signed in with a password.

2. Saytı bazaya qoşmaqConnecting the website

Depodakı assets/mo-config.js faylını açın və iki dəyəri yazın:

Open assets/mo-config.js in the repository and fill in the two values:

window.MO_CONFIG = {
  SUPABASE_URL: 'https://xxxxxxxxxxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'
};

Faylı yadda saxlayıb GitHub-a göndərin (commit + push). 1–2 dəqiqə sonra sayt yenilənir. Bundan sonra saytınız/admin/ ünvanını açıb e-poçt və şifrənizlə daxil ola bilərsiniz.

Save the file and push it to GitHub. The site redeploys in a minute or two. After that open yoursite/admin/ and sign in with your email and password.

Faylı redaktə etmək istəmirsinizsə: /admin/ səhifəsini açın — panel özü bir forma göstərəcək və dəyərləri həmin brauzerdə saxlayacaq. Amma bu halda saytdakı Instagram qalereyası işləməyəcək, çünki ziyarətçilərin brauzeri həmin dəyərləri bilmir. Qalereya üçün fayl mütləq doldurulmalıdır. If you would rather not edit the file: just open /admin/ — the panel shows a form and stores the values in that browser. But then the website gallery will not work, because visitors' browsers do not have those values. For the gallery, the file must be filled in.

3. Instagram qalereyasıThe Instagram gallery

Saytın qalereyası birbaşa @master__optik hesabının paylaşımlarını göstərir. Panel Instagram-dan paylaşımları çəkib bazaya yazır, sayt isə bazadan oxuyur — beləliklə ziyarətçilərin brauzerində heç bir Instagram açarı görünmür.

The website gallery shows the posts of @master__optik itself. The panel pulls the posts from Instagram into the database and the website reads them from there, so no Instagram token is ever exposed to visitors.

Bir dəfəlik hazırlıq

One-time preparation

Hesab «Professional» olmalıdırThe account must be Professional

Instagram tətbiqi → Profil → Settings and privacy → Account type and tools → Switch to professional account → Business. Adi (şəxsi) hesabla API işləmir.

Instagram app → Profile → Settings and privacy → Account type and tools → Switch to professional account → Business. The API does not work with a personal account.

Meta developer hesabıMeta developer account

developers.facebook.com → Log in (Facebook hesabı ilə) → My Apps → Create App.

developers.facebook.com → Log in with a Facebook account → My Apps → Create App.

Tətbiq yaradınCreate the app

Ad: Master Optik Sayt. Use case sualında Other → tip: Business → Create app. (Bu tətbiq yalnız sizin öz hesabınıza giriş üçündür, yoxlamaya göndərmək lazım deyil.)

Name it Master Optik Site. For the use case pick Other → type Business → Create app. (This app only reads your own account; it never needs App Review.)

Instagram məhsulunu əlavə edinAdd the Instagram product

Tətbiqin panelində Products siyahısından Instagram → Set up → API setup with Instagram login bölməsi.

In the app dashboard find Instagram in the product list → Set up → the API setup with Instagram login section.

Hesabı bağlayın və token alınConnect the account and generate a token

1. Generate access tokens → Add account → Instagram hesabınıza daxil olun və icazələri təsdiqləyin. Sonra Generate token → açılan uzun mətni tam kopyalayın. Bu token 60 gün etibarlıdır.

Under 1. Generate access tokens click Add account, log into your Instagram account and approve the permissions. Then press Generate token and copy the long string in full. The token is valid for 60 days.

Tokeni panelə yazınPaste the token into the panel

/admin/ → Instagram → tokeni sahəyə yapışdırın → Yadda saxla → İndi sinxronlaşdır. Bir neçə saniyəyə son 30 paylaşım gəlir.

/admin/ → Instagram → paste the token → Save → Sync now. The last 30 posts arrive within a few seconds.

Qalereyanı seçinCurate the gallery

Hər paylaşımın altındakı göz düyməsi ilə onu saytda gizlədə/göstərə, yuxarı-aşağı oxlarla sırasını dəyişə bilərsiniz. Sayt ilk 12 görünən paylaşımı göstərir.

The eye button hides or shows a post on the website; the arrows change its order. The website shows the first 12 visible posts.

Sonra nə etmək lazımdır? Demək olar ki, heç nə. Panel açılanda tokeni özü uzadır və gündə bir dəfə paylaşımları özü yeniləyir. Yeni paylaşımın saytda görünməsi üçün sadəcə paneli açmaq (və ya İndi sinxronlaşdır basmaq) kifayətdir. What next? Almost nothing. The panel refreshes the token by itself and re-syncs the posts once a day whenever it is opened. To get a new post onto the site, just open the panel — or press Sync now.

4. Gündəlik istifadəDaily use

BölməSection Nə üçündürWhat it is for
İdarə paneli / Dashboard Bu ayın satışı, açıq sifarişlər, götürülməyi gözləyən eynəklər, azalan mallar. Sales this month, open orders, glasses waiting for pickup, low stock.
Müştərilər / Customers Müştəri kartı: telefon, qeyd, bütün reseptləri və bütün sifarişləri. Resepti çap edib müştəriyə vermək olar. Customer card: phone, notes, every prescription and every order. A prescription can be printed and handed to the customer.
Sifarişlər / Orders Çərçivə + linza sətirləri, vədə tarixi, ödəniş və qalıq. Status «Təhvil verilib» olanda anbardan avtomatik silinir. Frame + lens lines, promised date, paid and balance. Setting the status to Delivered deducts the items from stock automatically.
Anbar / Stock Mallar, sayı (+/− düymələri ilə), maya və satış qiyməti, minimum həddə çatanda xəbərdarlıq. Products, quantity (with +/− buttons), cost and sale price, a warning when the minimum is reached.
Instagram Saytdakı qalereya. Paylaşımların seçimi və sırası. The website gallery: which posts show and in what order.
Sayt mətnləri / Site copy Saytdakı başlıqlar, xidmət təsvirləri, ünvan və iş saatları — üç dildə. Headlines, service descriptions, address and opening hours — in all three languages.

Ehtiyat nüsxə

Backups

Ayda bir dəfə Ayarlar → Ehtiyat nüsxə → Yüklə basın. Bütün müştəri, sifariş və anbar məlumatları bir JSON faylı kimi kompüterinizə yüklənir.

Once a month press Settings → Backup → Download. All customers, orders and stock are saved to your computer as a single JSON file.

5. Problem olarsaTroubleshooting

Panelə girə bilmirəm

I cannot sign in

Şifrəni unutmusunuzsa, giriş səhifəsində Şifrəni unutmusunuz? düyməsi bərpa linki göndərir. Alınmazsa: Supabase → Authentication → Users → istifadəçi → Reset password.

Use Forgot your password? on the sign-in screen. If that fails: Supabase → Authentication → Users → the user → Reset password.

Instagram sinxronizasiyası alınmır

Instagram sync fails

Brauzer bəzən birbaşa Instagram sorğusunu bloklayır. Bu halda Əl ilə import düyməsini basın: açılan linki yeni tabda açın, göründüyü mətni (JSON) tam kopyalayıb pəncərəyə yapışdırın və Import et basın. Nəticə eynidir.

Some browsers block the direct call to Instagram. Press Manual import: open the link it shows in a new tab, copy the JSON text you see there, paste it back and press Import. The result is identical.

Token 60 gündən çox işlədilməyibsə, artıq etibarsızdır — yuxarıdakı 5-ci addımı təkrarlayıb yeni token alın.

If the token has not been used for more than 60 days it has expired — repeat step 5 above to generate a new one.

Saytda qalereya köhnə görünür

The website gallery looks stale

Instagram-ın şəkil linkləri müvəqqətidir. Panel şəkillərin daimi surətini Supabase Storage-a yazır; alınmadıqda gündəlik sinxronizasiya linkləri təzələyir. Şəkillər boş görünürsə, panelə girib İndi sinxronlaşdır basın.

Instagram's image links are temporary. The panel mirrors the images into Supabase Storage; where that is not possible the daily sync refreshes the links instead. If images look blank, open the panel and press Sync now.

Qalereya ümumiyyətlə görünmür

No gallery at all

Yoxlayın: assets/mo-config.js faylında hər iki dəyər yazılıb və commit edilib; panelin Instagram bölməsində ən azı bir paylaşım görünən vəziyyətdədir. Bunlar yoxdursa, sayt dizaynerin qoyduğu köhnə şəkilləri göstərməyə davam edir — yəni sayt heç vaxt boş qalmır.

Check that both values in assets/mo-config.js are filled in and committed, and that at least one post is visible in the panel's Instagram section. Until then the site keeps showing the designer's original photos — it never ends up empty.
