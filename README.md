## Qeyd

`d6`–`d11` tək fayldır: şəkillər HTML-in içinə yerləşdirilib, ona görə hər biri 1.6–2.3 MB-dır.
Xarici `images/` qovluğuna ehtiyacları yoxdur. Yüngülləşdirmək lazımdırsa, deyin — şəkilləri
`../images/` ünvanına bağlayaram, o zaman hər səhifə ~60 KB olar.
